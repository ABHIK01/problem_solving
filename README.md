# problem_solving

This repository contains algorithm solutions and design pattern implementations.

## Contents

### Educative
- **Heap**: Algorithm implementations for heap-based problems
  - `MaximizeCapital.java`: Solution for maximizing capital using heap data structures

### Design Patterns
- **Comprehensive E-commerce Use Case**: Demonstrates Factory, Builder, and Singleton patterns
  - `Singleton/`: Database Connection Manager implementation
  - `Factory/`: Payment processor factory with multiple payment types
  - `Builder/`: Complex order construction with fluent interface
  - `Demo/`: Complete working example showing all patterns together

See `DesignPatterns/README.md` for detailed documentation and usage examples.
